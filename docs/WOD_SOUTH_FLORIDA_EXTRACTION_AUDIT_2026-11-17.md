## Format observation requiring resolution

The decompressed content is fixed-width WOD-like ASCII, not NetCDF: 80-byte records with CRLF separators and repeated multi-line cast blocks. Each cast-start line begins with `Q` (861 GLD, 3 MRB, 200 PFL, 3,725 MBT, 2,286 XBT).

The WOD23 User Manual describes 80-character ASCII records and states that the first byte is `C` for WOD23/WOD18, `B` for WOD09/WOD05, and `A` for WOD01. The observed `Q` marker therefore does not match the documented release markers. The query's WOD release/version and selected export format were not preserved in the copied query criteria, so do not assume these files are confirmed WOD23 native-format files. Resolve the marker against the exact WODSelect export/version or NOAA's sample reader before parsing.

Official references:
- [WOD23 User Manual, file structure and ASCII record format](https://repository.library.noaa.gov/view/noaa/66124/noaa_66124_DS1.pdf)
- [NOAA: Reading WOD data](https://www.ncei.noaa.gov/access/world-ocean-database/read-wod.html)
- [NOAA WOD landing page and documentation](https://www.ncei.noaa.gov/products/world-ocean-database)

## What this audit does and does not establish

Established:
- The five uploaded gzip files are readable and internally complete at the gzip level.
- The number of cast-start records in each file exactly matches the WODSelect counts copied for GLD, MRB, PFL, MBT, and XBT.
- The content has 80-byte fixed-width records and CRLF separators.

Not yet established:
- The WOD release/version, actual export option, observed-versus-standard level selection, or QC/IQuOD flag retention.
- Meaning of the observed `Q` cast-start marker.
- Parsed date/time, coordinates, cast identifiers, depth/pressure, temperature values/units, or QC flags.
- Unique cast count after deduplication, valid profile depth coverage, deepest valid temperature sample, seabed separation, or near-bottom eligibility.
- Whether OSD and CTD archives were generated and remain available.
